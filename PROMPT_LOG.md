## Задание 2: Разработка прототипа агента на Go
**Инструмент:** opencode (gemma-4-31b-it)

### Промпт 1
**Промпт:** "Для реализации прототипа агента на Go необходимо развернуть инфраструктуру брокера сообщений NATS. Создай базовый `docker-compose.yml` для запуска сервера NATS с открытыми портами 4222 и 8222."

**Результат:** Создан конфигурационный файл `docker-compose.yml`, позволяющий развернуть сервер NATS в Docker-контейнере. Брокер доступен по стандартному порту 4222, настроен порт мониторинга 8222. Инфраструктура готова к подключению Go-агентов.

### Промпт 2
**Промпт:** "Реализуй функционал агента 'Оценка риска' в папке `agent/`. Код должен включать: инициализацию Go-модуля, установку зависимости nats.go, определение структур данных для запроса и ответа, алгоритм расчета риск-скора на основе весов маркеров и логику подписки на очередь NATS `tasks.risk_assessment` с использованием Queue Group для балансировки. Обеспечь строгую проверку всех ошибок и полное отсутствие комментариев в коде."

**Результат:** Инициализирован Go-модуль `lab13/agent`. Создан файл `main.go` с реализацией бизнес-логики оценки рисков и транспортного слоя на базе NATS. Внедрена система весов для маркеров мошенничества и механизм автоматического определения вердикта (LOW/MEDIUM/HIGH). Реализована поддержка горизонтального масштабирования через Queue Group `risk_assessors`. Все возвращаемые ошибки обрабатываются в соответствии с идиомами Go.

### Промпт 3
**Промпт:** "Реализуй тестирование Go-агента, используя подход Table-Driven subtests для всех сценариев расчета риска (границы вердиктов, неизвестные маркеры, экстремальные значения). Добавь интеграционный тест JSON Pipeline для проверки корректности сериализации данных. Пиши код без комментариев."

**Результат:** Создан файл `main_test.go` с расширенным набором тестов. Реализованы подтесты для всех граничных значений риск-скора (30, 31, 80, 81) и проверка устойчивости к некорректным маркерам. Добавлен тест полной цепочки сериализации/десериализации JSON. Из всех файлов исходного кода и тестов удалены комментарии. Все тесты проходят успешно.
